Tools

Files not opening in a non-root file manager?
Run Access test, then Make readable (or Make writable).
For a permanent fix run the helper inside Ubuntu: sh /data/.ubuntu-data-tools/setup-sharing.sh
An archive extracted in Ubuntu keeps its own private permissions (e.g. 0700), so Android cannot open it. After extracting run share-fix /data/<folder> in Ubuntu (installed by that script), or press Make writable here, or turn on Auto-fix permissions on mount. Diagnostics also lists which folder is blocked and why. Download log saves the log to your Download folder.
